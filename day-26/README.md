# اليوم 26 — واجهة Gradio: حوّل السكربت لتطبيق

> المرحلة: **نشر وختام** · الأدوات: **Gradio ChatInterface**

## 🎯 المشكلة
الكود ما بيبهر أحد. التطبيق اللي بيشتغل قدام عيونهم هو اللي بيبهر.

## 🧠 شو رح تتعلم
- بناء واجهة محادثة بـ 10 أسطر
- ربط السلسلة بالواجهة
- تجهيز التطبيق للنشر

## ▶️ التشغيل
```bash
cp .env.example .env      # ضع HF_TOKEN و LANGSMITH_API_KEY
pip install -r requirements.txt
python day-26/app.py
```

## 📸 النتيجة
ضع لقطة شاشة في `assets/` (للتطبيق + لقطة LangSmith Trace من اليوم 11 وما بعد).
