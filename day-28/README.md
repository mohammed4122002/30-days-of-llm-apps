# اليوم 28 — اربط عالمين: n8n + وكيل LangChain

> المرحلة: **نشر وختام** · الأدوات: **FastAPI + Webhook + n8n**

## 🎯 المشكلة
كيف أستفيد من خبرتي بـ n8n مع قوة الذكاء الاصطناعي المبرمج؟

## 🧠 شو رح تتعلم
- تحويل السلسلة إلى API
- استدعاؤها من عقدة HTTP Request بـ n8n
- متى n8n ومتى كود

## ▶️ التشغيل
```bash
cp .env.example .env      # ضع HF_TOKEN و LANGSMITH_API_KEY
pip install -r requirements.txt
python day-28/app.py
```

## 📸 النتيجة
ضع لقطة شاشة في `assets/` (للتطبيق + لقطة LangSmith Trace من اليوم 11 وما بعد).
