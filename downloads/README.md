# التنزيلات

ملفات مجمّعة للتنزيل بضغطة وحدة. افتح الملف واضغط زر التنزيل (Download raw file) أعلى اليمين.

| الملف | المحتوى |
|---|---|
| `instagram-captions.md` | كابشن إنستغرام لكل الريلز (اليوم 0 والأيام 1 إلى 30)، جاهز للنسخ |
| `carousels-pdf.zip` | كل الكاروسيلات PDF: اليوم 0 والأيام 1 إلى 30 (31 ملف) |
| `reels-day-00-10.zip` | ريلز اليوم 0 والأيام 1 إلى 10 |
| `reels-day-11-20.zip` | ريلز الأيام 11 إلى 20 |
| `reels-day-21-30.zip` | ريلز الأيام 21 إلى 30 |

نفس الملفات موجودة كمان بمجلد كل يوم (`day-XX/carousel.pdf` و `day-XX/reel.mp4`).
